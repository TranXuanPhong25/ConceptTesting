# XRepoTest: Benchmarking Multilingual Repository-Level Unit Test Generation for LLMs

Reviewed 2026-10-15. Full arXiv v2 read (20,558 words; SHA-256 `adc3ba8f63176e442b0e139e09f8f207aea8a72a6fad7ac465b7cf593f1d5db6`).

XRepoTest has 3,642 focal functions from public repositories across Rust (931), Go (706), Julia (684), PHP (646) and Ruby (675). It compares standard, LSP, file and BM25/UniXCoder retrieval context, executes generated tests in language-native Docker images, and reports compile/pass/coverage/mutation plus the proposed Invocation Rate (IR). IR catches suites that pass or get coverage by invoking a wrapper/helper instead of the assigned focal function. The paper finds only 9.7% of TPR-passing suites fail IR overall, but this reaches 28.3% in Rust and 19.2% in Ruby; failure taxonomy identifies API hallucinations, type/memory, logic/assertions and scaffolding issues. It also includes small agentic/repair evaluations.

This is a useful *complementary* benchmark and evaluation-design paper. It is **not** issue-to-BRT/F2P testing: Java and Python are intentionally excluded, Defects4J is related work only, no BugsInPy/SWT-Bench tasks are used, and tests target current source with no developer behavior oracle. Mutation testing is supported only for Go, Rust and Ruby; no RCA labels.

The author-linked [MIT repository](https://github.com/solis-team/XRepoTest/tree/39fb6ab3173136d3dac2d38ed7c98baf6c470270) is substantive and includes the complete CLI, prompt/context/generation/eval/repair pipeline, language Docker evaluators and tests. The public ungated [MIT-tagged HuggingFace dataset](https://huggingface.co/datasets/solis-soict/xrepotest) has 40 JSONL files (~1.69 GB): base data is ~105 MB, LSP ~106 MB, RAG ~1.48 GB. The README's fetch and run commands use Docker images and support any OpenAI-compatible model endpoint. A single-language local-Qwen run is reasonably straightforward, but Qwen2.5-Coder-7B differs from the paper's Qwen3-8B and Qwen3-Coder-Next-80B, so it is an independent evaluation rather than exact replication. Full 14-model rerun is conditional and heavier; Docker tags are mutable `latest` and raw `repo_data/` is not distributed, though published data and prebuilt images are for evaluation.

**Recommendation:** if a repository-level unit-test benchmark outside Java/Python is useful, this is the strongest public-data/custom-Qwen route found. For the primary Defects4J bug-reproduction direction, it is supporting evidence only; #74 is much more direct and its results can be reanalyzed without generation calls. No code, data or model was run.
