# Exploring Prompt Engineering in LLMs for Automated Unit Test Generation: A Large-Scale Study

This repository contains the replication package for the paper **"Exploring Prompt Engineering in LLMs for Automated Unit Test Generation: A Large-Scale Study"**. The study evaluates the effectiveness of various Large Language Models (LLMs) and prompt engineering techniques for generating unit tests. It includes all the necessary tools, dependencies, and generated test results.

## Abstract

Unit testing, crucial for identifying bugs in code modules like classes and methods, is often neglected by developers due to time constraints. Automated test generation techniques have emerged to address this, but often lack readability and require developer intervention. Large Language Models (LLMs), like GPT and Mistral, show promise in software engineering, including in test generation. However, their effectiveness remains unclear.

This study presents a comprehensive investigation of LLMs, evaluating the effectiveness of four LLMs and five prompt engineering techniques for unit test generation. We analyze 216,300 tests generated by the selected advanced instruct-tuned LLMs for 690 Java classes collected from diverse datasets. We assess correctness, understandability, coverage, and test smell detection capabilities of LLM-generated tests, comparing them to EvoSuite, a popular automated testing tool. While LLMs show potential, improvements in test quality—particularly in reducing common test smells—are necessary. This study reveals the strengths and limitations of LLMs compared to traditional methods, paving the way for further research on LLMs in software engineering.

## Repository Structure

The repository is organized into the following directories:

- **Datasets**: Contains the three datasets (in JSON format) used for test generation: SF110, Defects4J, and CMD (Custom Dataset).
- **Dependencies**: Includes all necessary libraries (JAR files) for compiling the projects, especially those in the CMD.
- **Experiments-Scripts-And-Results**: Contains scripts and results (outputs) for each research question (RQ) and the tools used. It has five subdirectories:
  - **RQ1**: Scripts and results for Research Question 1.
  - **RQ2**: Scripts and results for Research Question 2.
  - **RQ3**: Scripts and results for Research Question 3.
  - **RQ4**: Scripts and results for Research Question 4.
  - **Test-Generation**: Code used to generate tests with OpenAI and MistralAI models.
- **Generated-Test-Suites**: Contains generated tests for each model (GPT-3.5-Turbo, GPT-4, Mistral 7B, Mixtral 8x7) and EvoSuite. Tests are labeled as "Compilable", "Raw", or "Syntactically-correct" for each dataset and class.
- **Prompt**: Contains the content of the prompts used to generate the test suites with the different models, including:
  - Zero-shot Learning (ZSL)
  - Few-shot Learning (FSL)
  - Chain-of-Thought (CoT)
  - Tree-of-Thoughts (ToT)
  - Guided Tree-of-Thoughts (GToT) (previously named ToT 2)
- **Tools**: Contains the tools used in this study:
  - [Checkstyle 10.14.2](https://checkstyle.sourceforge.io/)
  - [EvoSuite 1.2.1](https://github.com/EvoSuite/evosuite)
  - [Hamcrest-core 1.3](https://hamcrest.org/JavaHamcrest/distributables)
  - [JaCoCo 0.8.8](https://www.jacoco.org/jacoco/)
  - [JUnit 4.13.2](https://junit.org/junit4/)
  - [PMD 7.0.0-rc4](https://pmd.github.io/2023/09/30/PMD-7.0.0-rc4/)
  - [SpotBugs 4.8.3](https://spotbugs.github.io/)
  - [TsDetects 2.2](https://github.com/TestSmells/TestSmellDetector)

## Research Questions

1. **RQ1**: How does prompt engineering influence the generation of syntactically correct and compilable test suites by LLMs?
2. **RQ2**: Beyond syntactic correctness, how well do LLMs generate human-readable and maintainable test suites?
3. **RQ3**: How does the code coverage achieved by LLM-generated test suites compare to those generated by a Search-Based Software Testing technique?
4. **RQ4**: How do LLM-generated test suites compare to EvoSuite-generated test suites in terms of test smell prevalence?

## How to Use

1. **Clone the Repository**:
   ```sh
   git clone https://anonymous.4open.science/r/LLM4TS-0F76/
   cd LLM-Unit-Test-Generation
   ```
2. **Setup Dependencies**:
   Ensure all necessary dependencies are available by following the instructions in the `Dependencies` directory.

3. **Run Experiments**:
   Navigate to the `Experiments-Scripts-And-Results` directory and follow the instructions in the respective subdirectories to reproduce the experiments.

4. **Analyze Results**:
   The `Generated-Test-Suites` directory contains the generated tests, labeled accordingly. Use the provided tools in the `Tools` directory to analyze the test suites.
