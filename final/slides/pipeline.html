07 / ORCHESTRATORCONCEPTTESTER / HUMAN EVAL

Hai vòng lặp, một barrier

with self.run_lock():
    self.verify_or_write_manifest(tasks, metadata)
    for task in tasks:
        context = TaskContext(...)
        contexts.append(context)
        self.execute_stages(self.generation_stages, context)

    self.freeze_inputs(contexts)

    for context in contexts:
        context.inputs_frozen = True
        self.execute_stages(self.evaluation_stages, context)
THỨ TỰ

Sinh xong mọi task mới chấm

Không phải generate task A → chấm A → generate B. Barrier giữ output reference/PUT ở phía sau mọi input generation.

IDENTITY

Manifest và run lock

Ghi task/spec hash, metadata, settings, generator, stages, model, runtime sources và package versions.

Đổi config/source → dùng run directory mới.

KEY

15 / SANDBOXCONCEPTTESTER / HUMAN EVAL

Lời gọi Python nằm ở runtime/

# execution.py
write("job.json", job)
write("program.py", job["source"])
subprocess.Popen(["bwrap", "--unshare-all", ...])

# worker.py · load()
namespace = {"__name__": "__candidate__"}
exec(compile(source, "/work/program.py", "exec"), namespace)
fn = namespace[entry_point]
PROCESS BOUNDARY

execute(job) → worker.py

Sandbox không có network và không nhận API credentials. Host filesystem bị giới hạn; Python/dependencies được mount theo policy.

RESOURCE BOUNDARY

Per-input deadline

Worker giới hạn memory, CPU-call deadline và output. Parent có wall timeout; infrastructure failure khác program verdict.

LLM transport và sandbox execution là hai nhánh riêng: RecordedModelCalls gọi API; execute() chỉ chạy code.

failure_statuses = ("fail", "error", "timeout")
if first_status in failure_statuses \
   and second_status in failure_statuses:
    failing_indices.append(test_index)

if first_status != second_status:

19 / RUN MODESCONCEPTTESTER / HUMAN EVAL

Resume, replay và rescore khác nhau

LIVE · --mode run

Resume cùng run

Chạy lại đúng lệnh đã dùng, cùng source/config/model. Có checkpoint thì reuse; artifact thiếu có thể gọi model hoặc execute tiếp.

Đổi source/config: output directory mới.

READ-ONLY · --mode replay

Replay run tương thích

Đổi --mode run thành --mode replay trong đúng lệnh run; giữ cohort, arms, task IDs, budget và target.

Không tokenizer, model call hay sandbox execution. Thiếu artifact/manifest → lỗi.

FROZEN INPUTS · rescore

Chấm lại input đã lưu

Đọc batches đã freeze từ source run; không sinh input mới. Re-evaluate trong output mới, có thể execute reference/PUT nếu cache miss.

Phù hợp khi chuyển sang corrected references.

final/.venv/bin/python -m final.src.modular.rescore \
  --source-run <saved-run> --cohort <same-cohort.json> --artifacts <new-output>
