# UniXcoder: Unified Cross-Modal Pre-training for Code Representation

Reviewed 2026-10-27; research only.

[Primary paper](https://arxiv.org/html/2203.03850). [Author artifact](https://github.com/microsoft/CodeBERT/tree/master/UniXcoder).

Uses code, comments and serialized AST information during pretraining. Supports code representation and code-to-code search. Official repository supplies checkpoints and inference examples. Possible optional semantic retrieval channel, but functional similarity is not bug-mechanism equivalence; original results do not establish zero-shot concept-card ranking.
