# Vul-RAG: Enhancing LLM-based Vulnerability Detection via Knowledge-level RAG

Reviewed 2026-10-27; research only.

[Primary paper](https://arxiv.org/html/2406.11147v3). [Author artifact](https://doi.org/10.1145/3797277).

Separates functionality, vulnerability causes and fixing solutions. Retrieval mixes code, abstract purpose and detailed behavior with BM25/rank fusion; detection checks causes and fixes. Closest conceptual match to this corpus. Security/C-C++ evaluation differs from Python logic bugs. This is a design reference, not a requested reproduction.
