# Self-Supervised Bug Detection and Repair

Reviewed 2026-10-27; research only.

[Primary paper](https://proceedings.neurips.cc/paper/2021/file/ea96efc03b9a050d895110db8c4af057-Paper.pdf). [Author artifact](https://github.com/microsoft/neurips21-self-supervised-bug-detection-and-repair).

Represents code entities and typed relations, using learned models for bug localization/repair. Python implementation is available from the authors. Training and injected-bug distributions differ from HumanEval semantic faults. Reference for relational code features, not a ready-made concept retriever. No code copied or run.
