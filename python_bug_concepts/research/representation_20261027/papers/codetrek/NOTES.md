# CodeTrek: Flexible Modeling of Code using an Extensible Relational Representation

Reviewed 2026-10-27; research only.

[Primary paper](https://research.google/pubs/codetrek-flexible-modeling-of-code-using-an-extensible-relational-representation/). [Author artifact](https://github.com/ppashakhanloo/CodeTrek).

Relational databases represent program information; queries derive further relations; learned walks embed the database. Evaluated on four Python tasks. Relevant as a representation design reference. Our proposed fact table does not implement its neural model and cannot inherit its accuracy.
