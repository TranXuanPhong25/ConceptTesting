# CodeRetriever: Unimodal and Bimodal Contrastive Learning for Code Search

Reviewed 2026-10-27; research only.

[Primary paper](https://arxiv.org/abs/2201.10866).

Learns code/code and code/text alignment with contrastive objectives using documentation, names and comments. Supports semantic retrieval motivation. Does not by itself provide local causal bug labels; applying it to condition-sensitive concept retrieval requires a separate diagnostic. Abstract-level method review only.
