**What can be held fixed**

A pure representation experiment needs the same semantic propositions, raw inputs/outputs, alternatives, feedback access, executable tool affordances and budgets. If a semantic abstraction deliberately adds derived information, compare with raw evidence from the same source and count extraction cost. Do not silently add a gold relation, reference value or bug location only to the concept arm.

Fixed maximum calls are not identical actual resource use. V50 has the same number of paired final calls, yet tool prompts use 5,531 more input tokens. V34 includes truncation differences in two concept wins. V53's open arm creates many more atomic predicates; measured validation/runtime and logical/provider usage must be reported rather than assuming equal cost.

Generation experiments cannot require equal generated inputs without suppressing the intended treatment effect. Instead, match generation/oracle resources and evaluator policy, then use same-input replay as a separate oracle diagnostic. Validity filters should be compared on the same candidate universe; that is what v53 tests.

**Concept content, structure and total effects**

Semantic prose can be a concept representation. A prose arm with the same propositions is needed to ask whether typed structure adds value. C≈S>R can support semantic-content utility without supporting labels. C≈R with a stronger C-vs-direct result can indicate raw tool evidence rather than added abstraction.

Do not condition away treatment mechanisms. V49's valid-program yield is downstream of its prompt treatment, so equal detection among mutually capable tasks does not prove zero total effect. It also does not establish that taxonomy caused the gain: untyped decomposition/planning controls are missing. Keep intention-to-treat outcomes primary and those conditioned analyses diagnostic.
