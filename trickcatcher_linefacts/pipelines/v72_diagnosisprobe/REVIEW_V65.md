# v65 engineering review

Owner source review, 2026-10-25. This is not an independent review or authorization
for a new model experiment. No model requests or private outcomes were computed.

Reviewed issues and resolutions:

- Admission rejects constant-false events, expression None, identical normalized
  claims, unsupported module sites and AST-identical alternatives. The writer
  receives the same contract, source/spec clause IDs and a required replacement
  rationale. Module sites are omitted from the menu with an explicit count.
- Public checks are uninstrumented, replay both original and replacement, compare
  typed outputs, and repeat every public example under two seeds. Missing output,
  failed execution and incomplete budget are unknown, never a pass. Re-admission
  checks full hypothesis/source identity before execution. Finite examples do not
  establish general semantic validity.
- Public checks count against the unchanged256 execution cap. Remaining time,
  candidates and native executions are divided over remaining hypotheses;
  public failure blocks that hypothesis's search. No adaptive model rewrite or
  extra writer calls were added.
- Context and gate share one deterministic selector. Distinct non-public sensitive
  witnesses precede nonsensitive witnesses, with two shown per hypothesis.
  Equal-evidence raw receives identical evidence; inputs-only gets exactly that
  input union. Receipts record omissions and hash displayed evidence.
- Every fixed case must pass before cohort arm dispatch. Direct per-case entry
  repeats the local gate. Resume checks source/request/model/Python/configuration
  identity plus construction/delivery checksums. Old readiness is incompatible.
- The inherited shell entry named v57; both shell and ngrok_run CLI now invoke
  the integrated v65 pipeline.
  --prepare-only stops after gate, with no generator calls. A fresh reviewed
  readiness identity is required online.
- Oracle code is retained but not imported into preparation. Its combined worker
  reads canonical labels; wiring it directly into public evidence would violate
  separation. Ref10 integration is deferred.

Remaining limitations: rationale can still be wrong; public consistency is not
spec proof; bounded search can miss triggers; generated input validity is still
unverified; alternative sensitivity does not prove a bug; oracle errors remain.
The all-case gate can stop the next pilot, exposing unsupported cases rather than
masking them with one successful case. No detection improvement is claimed.

Validation: 88 targeted regression tests passed in10.62s; parent inventories
verified unchanged (v7:51files; v63:100files). No live model/evaluator calls.
