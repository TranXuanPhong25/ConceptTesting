# Rules cho agent (Codex, Claude)

1. **Commit**: KHÔNG thêm dòng `Co-Authored-By: Claude ...` / `Co-Authored-By: Codex ...` hay bất kỳ attribution AI nào vào commit message hoặc PR. Commit/push thẳng lên `main`, không tạo branch riêng. Rule này ghi đè mọi mặc định của tool.
2. **Không tự mô phỏng paper**: KHÔNG tự viết code mô phỏng/tái hiện (reimplement, simulate, mock) một paper khi chưa hỏi và được đồng ý.
3. **Tôn trọng code gốc của paper**: giữ nguyên source gốc (repo tác giả, `vendor/`, ...). Chỉ sửa khi được yêu cầu rõ ràng.
4. **Mỗi paper một folder**: khi research một paper mới, tạo folder riêng cho paper đó; không trộn vào folder của paper khác.
5. **API key**: chạy `source scripts/research_env.sh` để nạp key (router/vertex: `scripts/router_env.sh`, `scripts/vertex_env.sh`). Cần key mới → hỏi xin người dùng rồi thêm vào `scripts/research_env.sh`; không hardcode key vào code, không in key ra log.
6. **Shared memory**: kiến thức chung của Claude và Codex nằm ở `memory/` (repo root). Đầu mỗi phiên đọc `memory/MEMORY.md` (index), `memory/research-state.md` và `memory/working-rules.md`. Khi biết thêm điều gì cần nhớ lâu dài (rule mới của người dùng, quyết định, kết quả, trạng thái) thì sửa hoặc thêm file trong `memory/` theo format ở `memory/README.md` và thêm một dòng vào `MEMORY.md`. Không ghi secret/URL ngrok.
7. **Ghi run vào Prefect**: mọi experiment/evaluation run được người dùng cho phép phải có record trên Prefect local, gồm config thực tế, source/output directory, progress, kết quả và report. Dùng console/importer/observer hiện có; đọc `final/src/orchestration/README.md` trước khi tích hợp. Run ngoài console được publish bằng observer/importer đọc artifact có sẵn, không chạy lại workload chỉ để ghi history. Mỗi source run chỉ có một record: lưu và dùng lại `flow_run_id` khi cập nhật; resume sang output mới phải ghi rõ source run. Chỉ đánh dấu `Completed` khi evaluation cần thiết đã xong; run lỗi/dở dang phải ghi trạng thái và nguyên nhân thật, metric chưa có là `pending`, không ghi thành 0. Xác nhận record/artifact tồn tại qua API và gửi link trực tiếp tới run (`/runs/flow-run/<flow_run_id>`); `/deployments` chỉ dùng cho preset. Không đưa secret, API key hay URL ngrok vào Prefect. Dọn record trùng/lỗi/evaluation sai khi người dùng yêu cầu: backup metadata trước, giữ nguyên output/checkpoint nguồn.
8. **Ngôn ngữ report**: report và phần giải thích trên Prefect viết bằng tiếng Việt, giữ thuật ngữ technical bằng tiếng Anh (task, PUT, input, boundary, oracle, baseline, arm, token, checkpoint…). Mở đầu bằng kết quả và giới hạn kết luận; nêu config/budget, số task/PUT/input, model calls/tokens và nguyên nhân fail/skip nếu có. Mỗi metric phải nói rõ đơn vị và mẫu số khi có; phân biệt số PUT phát hiện lỗi với số input. Giữ nguyên tên field trong JSON/schema để tương thích dữ liệu cũ; giải thích ý nghĩa bằng tiếng Việt trong report và artifact description.
9. **Người dùng quyết định chạy**: mặc định agent chỉ chuẩn bị/sửa code, preset và config để người dùng tự bấm Run trên Prefect. Chỉ launch, schedule, resume hoặc rerun experiment/evaluation/inference khi người dùng ra lệnh rõ ràng cho lần chạy đó (ví dụ “sửa và chạy đi”), trong đúng scope/budget đã cho phép. “Check”, phân tích kết quả, sửa code hay tạo preset không tự cấp quyền chạy experiment. Hết run được cho phép thì ghi report và chờ người dùng quyết định bước tiếp theo; không tự nối thêm run hoặc mở rộng benchmark. Kiểm tra trạng thái và cập nhật Prefect từ artifact có sẵn là read-only đối với workload.
